# Assignment Management System

## Overview

Assignment Management System is a mobile application designed to simplify assignment tracking and management for both students and teachers. The app provides a centralized platform where students can view assignments, track deadlines, submit work, and monitor marks, while teachers can create assignments, review submissions, and assign marks.

## Problem Statement

Students often miss assignment deadlines, struggle to track pending work, and lack a single platform to monitor submissions and marks. Teachers need an efficient way to distribute assignments, review student work, and manage grading.

## Solution

The Assignment Management System provides separate interfaces for students and teachers, enabling efficient assignment management, submission tracking, and grading through a user-friendly mobile experience.

## User Types

### Student

* Login
* View Assignments
* Submit Assignments
* Track Deadlines
* View Marks
* Manage Profile

### Teacher

* Login
* Create Assignments
* View Student Submissions
* Assign Marks
* Manage Assignments
* Teacher Dashboard
